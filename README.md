# Car Rental Management System

## Overview

A full-stack web application developed for CPSC 3660 (Introduction to Database Systems) that streamlines vehicle fleet management, customer reservations, and rental operations for a multi-location car rental business.

## Features

- Vehicle registration and management
- Reservation creation and tracking
- Vehicle availability monitoring
- Store location management
- User authentication and authorization
- Vehicle search by make, model, and location
- CRUD operations for vehicles and reservations

## Technologies Used

- PHP
- MySQL
- HTML5
- CSS3
- JavaScript

## Database Design

The system utilizes a relational database architecture to manage vehicles, reservations, customers, and store locations. Relationships are maintained using primary and foreign keys to ensure data integrity and consistency.

## Installation

1. Clone the repository
   git clone https://github.com/yourusername/car-rental-system.git

2. Import the SQL database file into MySQL

3. Update database credentials in `database.php`

4. Run the application using XAMPP or WAMP
